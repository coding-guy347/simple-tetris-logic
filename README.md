# 俄罗斯方块 (Tetris) - 现代 C++ 纯手搓实现

一个基于 **C++20** 与 **SFML** 从零手搓的俄罗斯方块游戏。本项目不使用任何游戏引擎，旨在通过底层框架构建，深入实践面向对象设计、核心游戏循环、矩阵算法与内存管理。

## ✨ 核心特性 (Features)

- **现代 C++ 架构**：全面使用 C++20 标准，利用 `std::array` 构建静态多维数组，保证内存的连续性与访问效率。
- **7-Bag 随机算法**：摒弃纯随机生成，采用现代俄罗斯方块通用的“7格洗牌”机制，保证方块分布的绝对公平与平滑的手感。
- **帧率无关的时间步长 (Fixed Timestep)**：基于 `sf::Clock` 实现 `dt` 时间累加，分离逻辑更新与画面渲染，确保在 60Hz 或 144Hz 显示器下拥有完全一致的下落与操作速度。
- **纯数学矩阵旋转**：不使用三角函数计算，通过 `rotated[c][3 - r] = true` 的核心公式实现二维矩阵 90 度顺时针旋转。
- **智能居中补偿**：在旋转逻辑中动态计算方块的包围盒（Bounding Box），自动处理长条（I型）与普通方块的旋转圆心偏移，防止方块在旋转时发生视觉“漂移”。

## 🛠️ 技术栈 (Tech Stack)

- **语言**: C++20
- **图形库**: SFML 2.5.1
- **开发环境**: Visual Studio 
- **构建配置**: 自带 `SFML.props` 属性表，彻底解耦环境配置，实现开箱即用。

## 🧠 核心架构设计 (Architecture & Design)

项目遵循**数据与表现分离**的原则，主要分为以下几个模块：

1. **`Block` (方块逻辑)**：
   - 维护 7 种基础方块的硬编码矩阵模板。
   - 负责自身的位置更新（X/Y 坐标）以及碰撞检测（边界检测、下方已固定方块的检测）。
   - 包含高精度的旋转矩阵运算与居中修正逻辑。
2. **`Game` (游戏主循环与状态管理)**：
   - 封装核心的 `Run()` 循环，处理 `sf::Event` 事件驱动。
   - 实现 7-Bag 随机池算法（`ReFillBag`）。
   - 处理行消除逻辑（`DeleteCol`），支持底行消除后的上方数组数据整体下移，并重置顶部空行。
3. **`tools` (底层渲染封装)**：
   - 提供全局的坐标转换工具（`ToPixel_x/y`），将逻辑网格坐标无缝映射到物理像素坐标。
   - 封装 `RenderRect`，统一处理绘制、颜色填充与边框绘制。

## 🚀 如何运行 (How to Run)

本项目已经配置了工程级属性表（`SFML.props`），无需在系统中配置环境变量，实现真正的“开箱即用”。

1. 克隆本仓库到本地。
2. 使用 Visual Studio 打开 `.sln` 解决方案文件。
3. 确保你的编译平台是 **x64**。
4. 直接按 `F5` 编译并运行。
   *(注：工程已配置自动拷贝脚本，编译后会自动将所需 SFML 的 `.dll` 复制到输出目录，无需手动操作。)*

## 🎮 操作说明 (Controls)

- **↑ (上箭头)**: 旋转方块 (顺时针)
- **↓ (下箭头)**: 加速下落
- **← (左箭头)**: 向左移动
- **→ (右箭头)**: 向右移动

## 💡 踩坑与工程复盘 (Retrospective)

在纯手搓过程中，解决了一些非业务层面的工程问题：
- **旋转漂移问题**：通过计算旋转后有效方块的 `min_x, max_x, width, height`，动态计算 `offsetX` 和 `offsetY`，将非对称方块重新对准 4x4 矩阵的中心。
- **循环消除死锁**：在 `DeleteCol` 函数中，消行后通过 `row++` 抵消掉外层的 `row--`，实现了在同一帧内高精度排查连续多行消除的场景。
